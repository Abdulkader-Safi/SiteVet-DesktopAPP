105 checks on every page, each with a fix

The checks come from the sitevet audit engine, open-source and written in Rust. The app adds the window around it: progress you can watch, a report you can sort and search, and a history of every run.

105CHECKS · 15 CATEGORIES

Every page, every check

Core SEO, content, links, images, accessibility, security, performance, structured data and more. Each finding shows the markup that failed and how to fix it.

Fail Warn Info Pass

Audit several sites at once

Paste a list of URLs and choose how many run side by side. A site that fails does not stop the others.

A history of every run

Chart the score across runs and compare any two, category by category, with the rules fixed and broken in between.

See each page's score as it finishes

Pages appear with their score as soon as their checks are done, next to live fail, warn and pass counts. Cancel any time; finished runs go straight into history.

Export to HTML, Markdown or JSON

Save a run as an HTML report that prints to PDF, as Markdown for Word or an email, or as JSON for scripts.

Set your audit defaults once

Page limits, crawl depth, concurrency and which checks run live in Settings. Change one value for a single audit without touching the defaults.

No account, no uploads

Audits run from your machine, and runs go into a local SQLite file that the sitevet command-line tool reads too.

What the app looks like

The report, history, settings and export, in a dark and a light theme that follow your system.

About two minutes for a 100-page site

01

Enter a URL

Paste the start page, or a list of sites. Your saved defaults fill in the rest.

02

Wait while it crawls

It follows links on the same site, reads robots.txt and the sitemap, and checks each page.

03

Read the report

Start with the lowest-scoring page. Every finding says what failed and how to fix it.

04

Audit again

After a fix, run it again. History shows the change, rule by rule.

First launch

The builds are not code-signed yet. On macOS, open System Settings, Privacy & Security and click "Open Anyway" once. On Windows, click "More info" and then "Run anyway". The app tells you when a newer version is out.

Or build it yourself

With Rust installed, one command builds and installs it.

cargo +1.100.0 install --locked \
  --git https://github.com/Abdulkader-Safi/SiteVet-DesktopAPP
Is it free?

Yes. SiteVet and the sitevet engine are both MIT licensed, and the source is on GitHub.

Does it send my data anywhere?

No. Your computer fetches the pages of the site you audit, and the results stay in a file on your disk. The only other request is a check against GitHub for a newer version when the app starts.

Where are my runs stored?

In history.db in your system's data folder, for example ~/Library/Application Support/sitevet on a Mac. The sitevet command-line tool uses the same file, so runs from either one show up in both.

Can it check accessibility and Core Web Vitals in a real browser?

Yes. Turn on "Rendered checks in Chrome" and it runs axe-core and measures Core Web Vitals in the Chrome already installed on your computer.
